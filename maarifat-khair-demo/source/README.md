# معرفة خير: المنصة (الإصدار 3)

منصة خاصة بالكامل: لا يظهر شيء قبل الدخول إلا شاشة «الاسم + الرقم». ثلاثة أدوار فقط.

## الأدوار
- **المشرف الأول**: يراقب المشرفين ويمنحهم الصلاحيات (لكل صفحة) ويسحبها، يولّد الاسم والرقم، يقرر استثناءات مدة التجميد، يرى لوحة مجمّعة (حالات، قمع، محرك، أمان، سجل تدقيق) ويرد على الدعم الفني. تعليق الحسابات يحتاج اعتماد مشرف أول آخر.
- **المشرف**: يصنع الطلبات (ملفات المستفيدين وهو أمين عليها ويقر بموافقتهم مع مرجع إثبات)، يستقبل طلبات المقارنة ويقرر، يضغط «تم التواصل» فيُجمَّد الملفان 7 أيام، يفعّل ملفه بعدها بنفسه، يرفع طلب استثناء للمشرف الأول، ويلغي ملفات المستفيدين. لا حسابات للمستفيدين.
- **المشرف التقني**: صفحة واحدة: الدعم الفني (وصف المشكلة + تصنيفها).

## الدخول
الاسم: 3 كلمات عشوائية. الرقم: 12 رمزًا عشوائيًا. يولّدهما المشرف الأول ويُعرضان مرة واحدة. الصفحات الظاهرة وقدرات الخادم تتبع صلاحيات الحساب فقط.

## التشغيل
```
npm test                       # 45 اختبارًا
PORT=3000 node server/index.js --demo   # عرض ببيانات اصطناعية (حسابات تظهر في شاشة الدخول)
node server/index.js           # يطبع بيانات المشرف الأول الأول مرة واحدة
sh scripts/build-static.sh dist   # نسخة ثابتة للعرض (الخلفية داخل المتصفح)
```
بلا اعتماديات npm. Node 22.

## الهيكل
`server/app.js` منطق الأعمال، `core.js` المسارات، `http.js` الخادم والحجب، `crypto.js` تشفير مغلف + كلمات/رموز الدخول، `matching/engine.js` المحرك، `web/` الواجهة، `test/` الاختبارات، `docs/` المراجعة الأمنية وملاحظات الإنتاج.

## نموذج إنشاء الملف
ست خطوات مع تحقق لكل خطوة ومراجعة قبل الإيداع. معايير الطرف الآخر: **لا يهم** / **مرن** (يرفع الدرجة ولا يستبعد) / **صلب** (يستبعد، حتى 5). الجداول تتحول إلى بطاقات على الجوال.

## ملفات المشرفين (صلاحية «الاطلاع»)
صفحة لكل مشرف تعرض كل الملفات النشطة والمجمّدة لدى كل المشرفين ببيانات التوافق والبطاقة واسم المشرف (بلا اسم ولا هاتف ولا تاريخ ميلاد؛ تبقى الهوية عند المشرف صاحب الملف). بحث وتصفية بالجنس والمدينة والحالة، وفتح أي ملف لكل بياناته، و«مطابقة مباشرة مع ملفي»: يقيّم المحرك الملفين بالشروط من الجهتين ويبيّن السبب (شرطك/شرطه، العتبة، السعة)، وإن كان مؤهلًا ينشئ الاقتراح في طلبات المقارنة لدى الطرفين. الصلاحية `browse` مفعّلة افتراضيًا لكل مشرف ويسحبها المشرف الأول من لوحة الحسابات. كل اطلاع مسجّل في التدقيق.

## المرفقات
لكل ملف حتى 6 مرفقات (PDF أو صور حتى 2 م.ب) بسحب وإفلات أو اختيار. تُخزَّن مشفّرة بمفتاح خاص بالملف (`kek:<id>:F`)، لا يراها إلا المشرف صاحب الملف، لا تدخل المقارنة، وتُتلف مع إلغاء الملف.

## التوافق على بطاقة المقارنة
كل بطاقة تعرض حلقة التوافق الإجمالي (الدرجة المتبادلة) مع درجة كل اتجاه وتغطية البيانات، ومستويات الأبعاد الخمسة، وكل معلومات البطاقة دفعة واحدة، للطرفين.

## تسهيل الاستخدام (كبار السن وغيرهم)
- حجم خط بثلاث درجات (عادي/كبير/أكبر) من شاشة الدخول ومن القائمة، يُحفظ على الجهاز فقط، ويكبّر معه الأزرار ومناطق اللمس ويحوّل النماذج إلى عمود واحد.
- الرئيسية تبدأ بـ«المطلوب منك الآن» ثم «ماذا تريد أن تفعل؟» بأزرار كبيرة مشروحة، والتفاصيل مطوية.
- زر «رجوع» ظاهر في كل صفحة فرعية، و«كيف أستخدم هذه الصفحة؟» في كل صفحة يعرض دليلًا من سطرين أو ثلاثة.
- النموذج يقول «الخطوة 2 من 6»، والرسائل أكبر وتبقى أطول ولها زر إغلاق، و«إظهار الرقم أثناء الكتابة» في الدخول.

## التصميم
`web/styles.css`: رموز تصميم موحدة، وضع داكن تلقائي، شريط جانبي على الحاسوب وشريط تبويب سفلي + ورقة منزلقة بالإيماءة (نابض فيزيائي قابل للمقاطعة في `lib.js`) على الجوال، استجابة فورية عند الضغط، مواد شفافة للطبقات العائمة، واحترام تفضيلات تقليل الحركة والشفافية والتباين.

## محاكي المحرك
داخل التطبيق ويشغّل المحرك نفسه على 90 ملفًا اصطناعيًا. مبني على سبب ← نتيجة: ثلاثة أمثلة جاهزة (مرن/متوازن/صارم)، قمع عمودي يبيّن أين سقط كل ملف مع تمييز «استبعده شرطُك» عن «استبعده شرطُهم»، أزرار «جرّب بضغطة» لكل شرط يضيّق الخيارات مع أثرها المحسوب مسبقًا، فروق الأعداد بعد كل تغيير، تراجع، وجدول «كيف حُسب هذا الرقم؟» (الوزن × التقارب = النقاط) لكل اقتراح.
